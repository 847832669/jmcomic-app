# 液态玻璃效果

Android `2.30-glass.7` / versionCode `25` 的全局表面、底栏及移动选中透镜统一使用 [QmDeve/AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)。

## 组件来源

- 固定上游版本：`d4238c557e46271f29ec0e3d3ee211bcf58dc2e0`，1.1.0 API；2026-11-16 重新核对。
- `:liquidglass` 构建原版 Java 组件及 `liquidglass_effect.agsl`。着色器正文与上游一致，仅文件换行格式不同。
- 保留原始 MIT 许可证与版权声明，构建、坐标和生命周期兼容修改见 [NOTICE](liquidglass/NOTICE.md)。

## 统一渲染路径

`NavigationGlass.kt` 只负责四个入口、胶囊布局与手势。整个底栏与移动选中透镜通过 `GlassSurface → QmGlassHost → LiquidGlassView.bind(source)` 渲染，光学效果均由库内 `LiquidGlassimpl` 和原版着色器提供。

除导航透镜单独配置外，全局组件保留库默认折射与色散；底栏背景通过库提供的模糊和着色 API 单独设置磨砂材质，透明透镜取消自身着色，改为折射已合成的磨砂底栏。圆角按各组件尺寸设置，着色按日夜主题和文字对比度配置。

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 默认折射高度 / 导航透镜 | 20dp / 12dp | 使用密度换算后传入库的 px API |
| 默认折射偏移 / 导航透镜 | 70dp / 静止 20dp → 按压 45dp | 库自动转换为负方向偏移 |
| 默认色散 / 导航透镜 | 0.5 / 静止 0.15 → 按压 1.0 | 保留库内七次颜色采样 |
| 底栏背景模糊 | 12dp | 换算为 px 后调用库 API，库上限 50px |
| 透镜及其它表面模糊 | 0.01px | 保持库默认值与清晰折射 |
| 底栏着色 | 日间 / 夜间均为 0.5 | 使用当前主题 surface 色，50% 背景透视 |
| 选中透镜着色 | 0 | 不添加独立的主题色填充 |
| 选中透镜光学边缘 | 12dp | 静止图标走清晰前景层；按压恢复边缘折射与色散，放大后可透视下方底栏边框 |

底栏高度 64dp，选中透镜内缩 4dp，高 56dp，水平边距 20dp。增加内部留白。四个图标在静止时绘制在清晰前景层并从采样中淡出，避免边缘拉伸或重复轮廓；按压、拖动及切页时平滑切入透镜采样，保留原生折射与色散。透镜折射高度为 12dp，偏移从静止 20dp 增至按压 45dp，色散从 0.15 增至 1.0；均遵守库的最小 12dp 折射高度及 20dp 偏移限制。文字标签在光学层上方独立绘制，从采样源排除，避免折射、色散或重影影响阅读；点击及可访问性语义仍由原控件提供。根页面末尾避让从 80dp 增至 88dp。

点击、拖动与页面横滑共用选中状态；按下时透镜高度增至 72dp，上下超出底栏各 4dp，宽度放大 18%。透镜按实际尺寸重排，避免缩放纹理导致采样错位。超过系统触摸阈值后直接跟随手指，保留在透镜边缘按下的抓取位置。整体底栏按位移的 6% 同向偏移，上限为左右各 6dp；松手后底栏归位、透镜缩回并吸附目标页。拖动取消、纵向移出或组件销毁时清理交互状态。Compose 只负责位置、尺寸与弹簧动画，不替换库的折射算法。

普通表面采样环境背景；底栏采样页面。选中透镜的独立背景分支先绘制页面，再绘制库渲染的磨砂底栏及按交互进度淡入的四个图标，最后供透镜采样；透镜自身与文字标签均不参与采样。库的 tintAlpha=0 只表示不着色，输出仍然是完整的采样图像；透镜保留完整库材质，不裁成边框、不淡化整层。光学参数随按压进度平滑变化，文字始终清晰；放大后可透视下方底栏轮廓，并对滑过的图标应用原生光学效果。采样分支在底栏四周扩展 28dp，保留放大突出部分的背景，避免采样透明空白。通过屏幕坐标对齐 Compose 与原生 View，每个采样源只暴露该组件范围，避免递归和整屏 CPU 截图。

API 33+ 使用库原生效果；API 26–32 使用半透明兼容表面。低版本系统不宣称支持真实折射与色散。

## 验证

构建命令：`gradle testDebugUnitTest assembleDebug`。离线视觉场景仅存在于 debug 构建：

```shell
adb shell am start -n com.denia.jmreader/.GlassPreviewActivity --es theme light
adb shell am start -n com.denia.jmreader/.GlassPreviewActivity --es theme dark
```

场景使用独立设置存储，支持切换纯色、移动棋盘背景与弹窗；测试后 force-stop 再打开主界面，恢复应用原设置。

2026-11-16 验证结果：

- `2.30-glass.7` / 25 构建及 29 项 JVM 测试通过，已覆盖安装到 BSN-AN00 / API 37。真机验证日夜四个选中入口均无静止图标拉伸或文字重影；截图像素检查通过，选中色图标/标签没有出现在透镜上下边缘。按压、拖动、释放与取消回弹均恢复清晰静止状态，文字在交互期间持续清晰。系统字体放大至 1.3 后标签仍清晰且无裁切，测试后已恢复原设置；主界面四入口及页面横滑验证通过。
- `2.30-glass.6` / 24 已覆盖安装到 BSN-AN00 / API 37，APK 构建及 29 项 JVM 测试通过。真机验证日夜静止与按压材质、72dp 胶囊突出、左右跟手、松手切页与取消回弹；透明胶囊保持底栏的模糊背景。
- `2.30-glass.5` / 23 已覆盖安装到 BSN-AN00 / API 37，29 项 JVM 测试和 APK 构建通过。
- 真机通过分开的 DOWN / MOVE / UP 触控验证按压放大、左右跟手、松手吸附，以及 CANCEL 和纵向移出的状态恢复；拖动时整体底栏左右各偏移约 18px（设备密度 2.975，对应 6dp），释放后归位。
- 日夜磨砂背景、透明透镜、背景移动、弹窗、四个入口、页面横滑和本地浏览历史均验证通过。取消手势后的底栏区域与初始截图像素一致，日志未发现应用崩溃。

- BSN-AN00 / API 37 已覆盖安装 `2.30-glass.4` / 22，验证日间、夜间、纯色和棋盘背景、背景移动、弹窗打开与关闭。
