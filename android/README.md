# JM Reader for Android

JM Reader 的 Android 版本（Kotlin + Jetpack Compose），与 iOS 版使用同一数据源，在同一仓库维护。本分支当前版本为 **2.30-glass.7**（versionCode **25**），已合并上游 v2.30（`871aed1`）；下方发布包仍为 `2.19-glass.4`。

## 安装

系统要求 Android 8.0（API 26）及以上。在 [v2.19-glass.4 Release](https://github.com/847832669/jmcomic-app/releases/tag/v2.19-glass.4) 下载 `JMReader-Android-v2.19-glass.4.apk` 安装，附带 `SHA256SUMS.txt` 校验文件。该安装包为已覆盖安装到 BSN-AN00 真机验证的调试签名版本；也可按下方步骤自行构建。

[上游 Releases](https://github.com/denia-dev/jmcomic-app/releases) 提供上游原版安装包；本分支的主题、QmDeve 材质和评论增强以本仓库源码为准。覆盖安装要求签名一致，本地构建的签名配置见 `app/build.gradle.kts`。

## 功能

- 首页推荐货架与频道、搜索历史与类型/排序筛选、编号直达、官方分类浏览。
- 详情页：作者作品页、标签展开、章节列表，以及可展开、收起和复制的作品描述。
- 信息胶囊：在标签下显示浏览量与更新时间，支持日间和夜间配色。
- 评论页：点击下载右侧的「评论」后加载；滑动接近底部自动续载，支持刷新及失败重试；登录后可发表评论，失败保留草稿。
- 评论关键词屏蔽：在设置中添加、删除关键词并保存在本机；命中评论正文时隐藏对应评论及其回复分支。
- 阅读器：上下滚动、横向翻页和方向切换，图片自动解打乱还原，下一章预加载；自动记忆章节、页码和图片内滚动位置，支持续读及从头阅读。
- 本地浏览历史：个人页独立入口，无需登录，支持标题/作者搜索、查看详情、直接续读、单条移除与确认清空。
- 个人页：账号登录、云端与本地收藏、收藏夹、观看历史、阅读统计、每日签到、屏蔽标签与作者、线路设置和存储空间。
- 粉色主题、全局液态玻璃卡片与浮动底栏；外观支持跟随系统、日间或夜间，立即生效并重启保留。

## 漫画续读与本地浏览历史

打开已读漫画详情时，「开始阅读」自动变成「继续阅读」，下方显示上次章节与页码；点击恢复最后阅读位置，点击「从头阅读」回到第一章第一页。章节列表按该章节自己的进度恢复，书架最近阅读与历史列表中的续读入口共用保存记录。滚动与翻页模式切换保留当前页，返回或切后台时立即保存。

「个人 → 本地浏览历史」记录成功打开的在线作品及阅读入口，按最近浏览排序并去重，最多 500 本；打开详情但不阅读也会记录。标题和作者可搜索，点击作品进入详情，有阅读进度时可直接续读。单条移除和清空只处理浏览记录，阅读进度、收藏与搜索历史不受影响。数据只保存在本机；清除应用数据或卸载后不会保留。

升级自动读取旧版阅读进度，并将旧最近阅读作为本地浏览历史的初始记录。阅读进度按作品和章节分别保存，独立于浏览历史的容量限制。验证范围见 [阅读功能记录](READING_HISTORY.md)。

## 评论与详情信息

「个人 → 右上角齿轮 → 设置 → 评论关键词屏蔽」中，每次添加一个关键词，点击加号保存，点击词条右侧的关闭图标移除。任意一个词命中评论正文即可屏蔽，英文匹配忽略大小写；名单在本机持久化，无需登录。

作品详情中的评论按钮位于下载按钮右侧。打开评论页才请求首屏，滚动时自动加载后续页；连续页面均被屏蔽时继续请求，直至出现可见内容或接口结束。失败时保留已加载评论，点击「重试」恢复。

浏览量使用 `total_views`；更新时间与 Venera 的禁漫画源一致，使用 `addtime` 时间戳转换为本地 `yyyy-MM-dd` 日期，接口暂无单独的最后更新时间字段。缺失信息显示「—」。

当前支持移动 API 返回的全部评论分页及其实际父子关系。站点楼中楼的完整读取和回复发送尚未实现；接口研究、验证码限制与测试范围见 [COMMUNITY.md](COMMUNITY.md)。

## 构建

环境：JDK 17、Android SDK Platform 35、Gradle 8.7。在本目录创建 `local.properties` 指向本机 Android SDK，例如：

```properties
sdk.dir=C:/Android/Sdk
```

在 `android/` 目录执行：

```shell
gradle testDebugUnitTest assembleDebug
```

- APK：`app/build/outputs/apk/debug/app-debug.apk`
- 单元测试报告：`app/build/reports/tests/testDebugUnitTest/index.html`
- debug 构建附带离线视觉与评论测试 Activity；release 构建不包含这些调试入口。

## 外观与液态玻璃

入口：底部「个人」→ 右上角齿轮 →「外观」。默认跟随系统，选择日间或夜间后立即更新页面文字、背景和系统栏，并保存到本机；无需登录账号。

工具栏、卡片、搜索与输入框、筛选标签、主要按钮、弹窗、阅读器控制区、底栏和移动选中透镜，统一使用 QmDeve 玻璃材质。底栏保留四个入口和粉色选中反馈，支持点击、横向拖动和页面联动；底栏高度调整为 64dp，静止透镜高 56dp；按下时透明透镜增高至 72dp、上下超出底栏各 4dp，宽度放大 18%，跟随手指移动，整体底栏同向轻移最多 6dp，松手回弹；静止时图标绘制在清晰前景层，按压和拖动时图标参与透镜折射；文字标签始终在光学层上方清晰绘制；正文与漫画原图不受影响。参数与适配见 [液态玻璃说明](LIQUID_GLASS.md)。

所有玻璃表面使用 [QmDeve/AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView) 的实际 `LiquidGlassView` 组件，由 `:liquidglass` 源码模块提供。原 Java 组件与 AGSL 着色器保留，构建适配 SDK 35 / Java 17。普通表面保留库默认的 20dp 折射高度、70dp 折射偏移与 0.5 色散；导航透镜通过库 API 使用 12dp 折射高度，偏移从静止 20dp 平滑增至按压 45dp，色散从 0.15 增至 1.0，遵守库的参数范围。底栏背景通过库 API 使用 12dp 磨砂模糊与 0.5 主题着色，选中透镜和其它表面维持 0.01px 模糊；圆角按组件尺寸设置。来源版本、MIT 许可证和兼容修正见 [组件库说明](liquidglass/NOTICE.md)。

- Android 13 / API 33 及以上：GPU 模糊、AGSL 边缘折射、色散与材质着色。
- Android 8–12 / API 26–32：清晰、可操作的半透明表面。

通过 Compose / View 适配层调用组件库的 `bind()`。卡片采样环境背景，底栏采样页面内容；选中透镜采样已合成的磨砂底栏，透镜零着色，保留完整的原生液态玻璃折射、偏移与色散，图标在静止时走清晰前景层，按压、拖动及切页时平滑参与透镜采样；文字标签始终独立绘制且不参与光学采样，避免穿透磨砂层直接露出原图。采样源只排除透镜自身，避免递归叠加。弹窗使用屏幕坐标对齐背景，每个组件仅录制自身范围。底栏不再使用专用着色器或额外白色描边，光学效果由组件库原生管线提供。原 Kyant0 AGSL 与 CPU 渲染器已移除；保留已有图层采样和导航布局的历史授权声明。
